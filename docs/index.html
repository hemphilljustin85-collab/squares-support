Squares Support

Squares helps groups create and share classic 10×10 game-day boards, track scores, and record quarter winners.

Squares does not collect, transfer, hold, or distribute participant money, payments, wagers, entry fees, or prizes.

Getting started

  • Host: create an account, tap Create board, and share the six-character code.
  • Join: tap Join with code and enter the code from your host.
  • Reveal: once all 100 squares are claimed, the host schedules the random number reveal.
  • Report a problem: on any board, tap “•••” → Report board, or tap a square → Report name.
  • Delete your account: Account → Delete account.
